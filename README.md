# New Calculator

A simple calculator built with React + Vite.

## Run it

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Project structure

```
new-calculator/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx   # entry point
    ├── App.jsx    # calculator component
    └── App.css    # styles
```

Keyboard: digits, + - * /, Enter (=), Esc (clear), Backspace (delete).
